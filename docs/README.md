# docs

- `SwaraLM_paper.pdf` is the paper and the record of results. Its source is in `paper/`
  (`SwaraLM_paper.md`, `references.bib`, `build.sh`).
- The `STAGE*` files and `PROJECT_LOG.md` are development notes, written as the project
  progressed and left as they were. The Stage 3, 4a and 5 notes quote numbers from the
  earlier v1 extraction (for example allied-stratum P@1 of 0.303 and 0.193, LSTM 0.179,
  Transformer 0.154). Section 6.3 of the paper explains how v1 and v2 relate.
- `../results/stage4b_transformer_log_v1_extraction.txt` is likewise a v1 run.
